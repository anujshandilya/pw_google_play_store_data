# pw_google_play_store_data
🚀 Exploring Machine Learning with Google Play Store Data! 📊📱
I’m excited to share my latest project, where I applied Machine Learning concepts like Data Preprocessing and Exploratory Data Analysis (EDA) to analyze the Google Play Store dataset!
🔍 Key Steps in My Analysis:
✅ Data Preprocessing: Converted data types (object ➝ datetime, int, float) for better analysis.
✅ Feature Engineering: Organized columns based on relevance and analytical needs.
✅ Exploratory Data Analysis (EDA): Answered some interesting questions:
- What are the top 10 most popular categories?
- Which category has the highest installations?
- What are the top 5 installed apps in each category?
- Which category’s apps receive the most user reviews?

📊 I visualized the results using Matplotlib and Seaborn, making the insights more intuitive and impactful.
